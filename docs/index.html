Linux Privilege Escalation
Automation Toolkit

LPE-Audit is a Python-based, read-only Linux security auditing toolkit that identifies potential privilege-escalation risks, collects supporting evidence, and generates reports for human review.

Project Overview

Misconfigured permissions, privileged executables, Linux capabilities, scheduled tasks, service configurations, and sudo policies can create opportunities for privilege escalation. LPE-Audit automates selected read-only checks and organizes observations into structured reports.

Read-only auditing

Inspects selected Linux security configurations without attempting exploitation or automatic remediation.

Evidence collection

Associates findings with evidence to support investigation and manual validation.

Risk analysis

Classifies findings and supports risk prioritization for human review.

Structured reporting

Produces JSON and text reports, with report comparison and remediation-planning support.

Nine Security Audit Modules

01

SUID / SGID

Identifies files with SUID or SGID permission bits.

02

Linux Capabilities

Examines file capabilities that may grant privileged operations.

03

File Permissions

Checks selected filesystem permissions for unsafe access.

04

Sudo Policies

Reviews available sudo policy information for risky privileges.

05

Cron Configuration

Reviews selected scheduled-task configurations and permissions.

06

Systemd Services

Examines selected service configuration and permission conditions.

07

PATH Security

Checks PATH-related directory permissions and executable resolution.

08

Kernel Inventory

Collects kernel information for implemented audit checks.

09

Sensitive Files

Checks selected sensitive-file permissions for unsafe access.

Getting Started

Clone the repository and run the toolkit in a Linux environment. WSL2 with Ubuntu can be used for a demonstration.

git clone https://github.com/Shaikhshariq-tech/LPE-Audit.git
cd LPE-Audit

python3 main.py --help
python3 main.py --version

python3 main.py --full-scan --report-dir reports/my-audit

Individual scanners can also be selected through command-line options. Consult the README for the complete instructions and available options.

Responsible Use and Limitations

Authorized defensive auditing only.

Use LPE-Audit only on systems you own or are authorized to assess. It is designed for auditing, not exploitation or automatic privilege escalation. It does not automatically change system configuration or remediate findings.

Findings may include false positives and require manual verification. Some checks may be incomplete because of permissions, missing utilities, or environmental restrictions. A clean report or passing test suite does not prove that a system is secure or that every vulnerability has been detected.
